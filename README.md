# Nape-ballcase

Nape（menbou0202 氏の自作トラックボール）の公式 BallCase を土台にした、
ボールケースのバリエーション集。どちらのモデルも、ELECOM の交換用支持
ユニット（ボールローラー M-TU03SS。ソケット 8×7×4mm は M-BS10 / M-RS10
とも共通）を差し込む受けポケットを持ち、純正の支持窪みを置き換える。

## モデル

### 34mm 段付き（ballcase34/）

公式ケースと同じ下部の首（35mm）のまま Top ケースに嵌め、上で 44mm に
広げて 34mm ボールを収めるケース。

- 支持ユニット版: `Nape-BallCase-34mm-stepped-BS10.stl / .step`
  （ファイル名の BS10 は旧称の名残。使うユニットは M-TU03SS）
- ボール入口は Ø33.95。逆さにしても抜けず、出し入れも軽いことを
  印刷で確認済み。

### 25mm CAD 版（ballcase25/）

公式 25mm ケースを実測して CAD（build123d）で作り直したもの。ボール面は
解析球面 R13.25、上面の R8 フィレット、センサー窓 Ø13 と底面の六角
マグネット穴の位置も公式どおり。

- `Nape-BallCase-25mm-unitpockets-CAD.stl / .step`

## ポケット仕様

テストピースの印刷で決めた寸法（方位 0/120/240°、仰角 −26°、左右に
全深さの逃げ溝 3.5×4.4）。

- 34mm 版: 開口 8.0 × 7.7、深さ 3.35（床はボール中心から 21.10）
- 25mm 版: 開口 8.0 × 7.6、深さ 3.35（床はボール中心から 16.60）
  ※壁の曲率が違うため、25mm 版は高さが 0.1 小さいのが実測の最適値

## 組み付けの注意

- 底面の磁石は必ず付けた状態で評価すること。磁石でケースが正規の
  位置に座るため、未装着だとボールとセンサーの距離がずれて見える。
- その上で、ケースと本体の間に挟むシム（下記）でボールとセンサーの
  距離を微調整できる。球の色や支持方式によって最適値が動き、
  シムがあった方が調子が良い場合がある。実測の目安（SANWA 34mm球）:
  ボールローラー支持では黒は 0.5、赤・紫は 0〜0.3。ベアリング支持では
  黒は 0.5 で悪化し 0.4 以下が候補。0.7 は上げすぎで全色不可だった。
  調整範囲は 0〜0.5 と考えてよい。

### ケース下シム（ballcase34/、34mm 版用）

底面の外形（34.9×34.9）に合わせた板。センサー窓 Ø13 とマグネット部
Ø7.2 の抜き入り。

- `Nape-BallCase-34mm-bottom-shims.stl / .step`: 0.3 / 0.5 / 0.7 の3枚組
- `Nape-BallCase-34mm-bottom-shim-04.stl / .step`: 0.4 の3枚組

## ファイルについて

- 正本は `scripts/` の生成スクリプト（build123d）。STL / STEP は
  生成済みファイルを置いてある。STL は転送の都合で ASCII 形式
  （形状はバイナリ版と同一）。
